# Мое портфолио проектов в MS Excel

В этом репозитории собраны файлы с решениями практических задач по анализу данных, автоматизации расчетов и очистке выгрузок.

---

## 📁 1. Файл: `excel_tasks_solution.xlsx`
*Сборник задач на логику, поиск и парсинг текста.*

**Разбор листов и выполненных заданий внутри файла:**
* **ВПР** — Точный поиск наименований и цен из прайс-листа по артикулу товара.
* **ВПР интервальная** — Автоматическое присвоение оценок студентам на основе набранных баллов по шкале диапазонов.
* **ГПР** — Горизонтальный поиск и извлечение данных из горизонтально ориентированных справочников.
* **ЕСЛИ** — Расчет скорректированных зарплат и премий сотрудникам по вложенным логическим условиям.
* **ВПР+ЕСЛИ** — Динамический поиск оклада сотрудника одновременно по двум критериям: должности и номеру филиала.
* **Текстовые функции** — Очистка ФИО от мусорных пробелов, деление текста по столбцам и сборка строк в формат инициалов.

---

## 📁 2. Файл: `crm_support_analysis.xlsx`
*Анализ работы службы поддержки и выгрузки заявок из CRM-системы.*

**Разбор листов и выполненных заданий внутри файла:**
* **Основная выгрузка** — Анализ базы закрытых заявок клиентов с фиксацией даты создания, даты выполнения и полученных оценок качества.
* **Справочник ответственных** — Поиск и автоматическое распределение сотрудников, закрывших тикеты, на основе сквозного идентификатора `id заявки`.
* **Аналитика оценок** — Мэтчинг удовлетворенности клиентов и сопоставление выставленных баллов по `Телефону клиента` для выгрузки аналитических отчетов.

---

## 📁 3. Файл: `sales_and_hr_analytics.xlsx`
*Комплексный анализ персонала, KPI и многокритериальный анализ продаж.*

**Разбор листов и выполненных заданий внутри файла:**
* **Расчет KPI премий** — Автоматизация начисления бонусов по двум сценариям («Мягкий» через `ИЛИ` и «Жёсткий» через `И`) на основе стажа работы сотрудников и процента выполнения плана.
* **Статистика персонала** — Расчет количественных показателей штата сотрудников (по полу, городам, возрастным группам) и фильтрация текстовых данных по маскам и вхождениям символов.
* **Анализ фондов оплаты (ФОТ)** — Селективное суммирование бюджетов и надбавок окладов с помощью формул с условиями.
* **Многокритериальный анализ продаж** — Построение аналитической матрицы для подсчета объема заказов и суммарной выручки по двум независимым условиям одновременно (конкретная номенклатурная позиция товара + региональный филиал).

---

## 📁 4. Файл: `index_match_and_error_handling.xlsx`
*Продвинутый двумерный поиск через ИНДЕКС/ПОИСКПОЗ и аудит расчетов.*

**Разбор листов и выполненных заданий внутри файла:**
* **Поиск ИНДЕКС** — Извлечение наименований и цен товаров по артикулу с помощью гибкой связки функций `ИНДЕКС` и `ПОИСКПОЗ` (альтернатива `ВПР` для случаев, когда ключевой столбец поиска находится правее извлекаемых данных).
* **Маркетинговая аналитика** — Расчет затрат на привлечение одного клиента по разным рекламным каналам. Реализована обработка пустых значений и деления на ноль с выводом кастомного текста «Нет данных».
* **Мультивалютный пересчет** — Динамический расчет бюджетов в долларах и евро на основе ячеек с актуальным валютным курсом.
