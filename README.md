# Мое портфолио проектов в MS Excel

В этом репозитории собраны файлы с решениями практических задач по анализу данных, автоматизации расчетов и очистке выгрузок.

---

## 📁 1. Файл: `excel_tasks_solution.xlsx`
*Сборник задач на логику, поиск и парсинг текста.*

**Разбор листов и выполненных заданий внутри файла:**
* **ВПР** — Точный поиск наименований и цен из прайс-листа по артикулу товара.
* **ВПР интервальная** — Автоматическое присвоение оценок студентам на основе набранных баллов по шкале диапазонов.
* **ГПР** — Горизонтальный поиск и извлечение данных из горизонтально ориентированных справочников.
* **ЕСЛИ** — Расчет скорректированных зарплат и премий сотрудникам по вложенным логическим условиям.
* **ВПР+ЕСЛИ** — Динамический поиск оклада сотрудника одновременно по двум критериям: должности и номеру филиала.
* **Текстовые функции** — Очистка ФИО от мусорных пробелов, деление текста по столбцам и сборка строк в формат инициалов.
