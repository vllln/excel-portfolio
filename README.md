# Мое портфолио проектов в MS Excel

В этом репозитории собраны файлы с решениями практических задач по анализу данных, автоматизации расчетов, очистке выгрузок и бизнес-моделированию.

---

## 📘 Основной курс

### 1. Файл: `excel_tasks_solution.xlsx`
*Автоматизация рутинных расчетов, логика подстановок и парсинг текста.*

* **Лист «ВПР»** — связывание таблицы заказов со справочником номенклатуры товаров и автоматическое подтягивание цен по артикулу.
  * *Формула поиска наименования:* `=ВПР(A25; $F$25:$H$35; 2; 0)`
  * *Формула поиска цены за шт.:* `=ВПР(A25; $F$25:$H$35; 3; 0)`
* **Лист «ВПР интервальная»** — автоматическое присвоение текстовых или числовых оценок студентам на основе набранных баллов по заданной шкале интервалов.
  * *Формула вывода оценки:* `=ВПР(B73; $G$73:$H$76; 2; 1)` *(Интервальный режим с параметром `1/ИСТИНА`)*
* **Лист «ГПР»** — извлечение информации из горизонтально ориентированных таблиц-справочников (поиск параметров в строках вместо столбцов).
* **Лист «ЕСЛИ»** — расчет скорректированных окладов с учетом минимального порога оплаты труда и диверсифицированных премий сотрудникам.
  * *Зарплата с ограничением:* `=ЕСЛИ(C113<15000; 15000; C113)`
  * *Вложенная премия:* `=ЕСЛИ(B113="Менеджер"; C113*0,2; ЕСЛИ(B113="Стажер"; 0; 5000))`
* **Лист «ВПР+ЕСЛИ»** — динамический поиск оклада сотрудника одновременно по двум критериям: его должности и номеру регионального филиала.
  * *Формула сквозного поиска:* `=ВПР(B139; $F$139:$H$145; ЕСЛИ(C139=1; 2; 3); 0)`
* **Лист «Текстовые функции»** — Data Cleaning (очистка данных), удаление мусорных пробелов, контролируемое деление ФИО на столбцы, изменение регистров и сборка инициалов.
  * *Удаление лишних пробелов:* `=СЖПРОБЕЛЫ(A176)`
  * *Формат ФАМИЛИЯ имя:* `=ПРОПИСН(D176)&" "&СТРОЧН(E176)`
  * *Сборка формата Фамилия И.О.:* `=D176&" "&ЛЕВСИМВ(E176;1)&"."&ЛЕВСИМВ(F176;1)&"."`

### 2. Файл: `sales_and_hr_analytics.xlsx`
*Продвинутая агрегация данных, учет KPI премий и многокритериальный анализ продаж.*

* **Лист «Расчет KPI премий»** — автоматическое начисление бонусов сотрудникам по двум моделям («Мягкий» сценарий через `ИЛИ` и «Жёсткий» сценарий через `И`) на основе их стажа и процента выполнения плана.
  * *Мягкий сценарий (выполнение хотя бы одного KPI):* `=ЕСЛИ(ИЛИ(I17>5; J17>=90%); H17*0,1; 0)`
  * *Жесткий сценарий (выполнение всех KPI одновременно):* `=ЕСЛИ(И(I17>5; J17>=90%); H17*0,1; 0)`
* **Лист «Статистика персонала»** — расчет количественных показателей штата сотрудников (по полу, городам, возрастным группам) и фильтрация текстовых данных по маскам и вхождениям символов с использованием функций `СЧЁТЕСЛИ` / `СЧЁТЕСЛИМН`.
* **Лист «Анализ фондов оплаты (ФОТ)»** — селективное суммирование бюджетов и надбавок окладов с помощью формул `СУММЕСЛИ` и `СУММЕСЛИМН`.
* **Лист «Многокритериальный анализ продаж»** — построение аналитической матрицы для подсчета объема заказов и суммарной выручки по двум независимым условиям одновременно (конкретная номенклатурная позиция товара + региональный филиал).

### 3. Файл: `index_match_and_error_handling.xlsx`
*Продвинутый двумерный поиск через ИНДЕКС/ПОИСКПОЗ и аудит расчетов.*

* **Лист «Поиск ИНДЕКС»** — извлечение наименований и цен товаров по артикулу с помощью гибкой связки функций `ИНДЕКС` и `ПОИСКПОЗ` как более мощной альтернативы `ВПР` (работает, когда ключевой столбец поиска находится правее извлекаемых данных).
* **Лист «Маркетинговая аналитика»** — расчет затрат на привлечение одного клиента (CAC) по разным рекламным каналам. Реализована обработка пустых значений и деления на ноль с помощью функции `=ЕСЛИОШИБКА(формула; "Нет данных")`.
* **Лист «Мультивалютный пересчет»** — динамический расчет бюджетов в долларах и евро на основе ячеек с актуальным валютным курсом.

---

### 4. Файл: `multi_domain_data_analysis.xlsx`
*Комплексный сквозной анализ коммерческих, кадровых и климатических данных.*

* **Лист «Продажи номенклатуры»** — анализ базы отгрузок подарочных наборов клиентам, расчет объемов партий и динамики выручки.
* **Лист «Кадры и Учет времени»** — моделирование фонда оплаты труда в валюте с группировкой по отделам компании, а также агрегация матрицы еженедельной занятости персонала (тайм-трекинг).
* **Лист «Метеорологический мониторинг»** — статистический анализ продолжительности светового дня и ночи, а также расчет частоты распределения погодных условий по месяцам.
* **Лист «Региональная дистрибуция»** — построение сводной матрицы сбыта книжной продукции по направлениям литературы и макрорегионам.

---

### 5. Файл: `conditional_formatting_inventory.xlsx`
*Автоматизация контроля складских запасов с помощью логического форматирования.*

* **Лист «Мониторинг остатков»** — динамическое выделение цветом строк таблицы. Написан логический алгоритм с использованием смешанных ссылок, который автоматически подсвечивает красным цветом позиции, где текущее количество товара на складе опустилось ниже установленного минимального запаса.
  * *Формула правила:* `=$E2<$F2` *(Знак `$` закрепляет только столбцы E и F, позволяя строкам смещаться при проверке вниз)*
