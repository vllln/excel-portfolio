# Мое портфолио проектов в MS Excel

В этом репозитории собраны файлы с решениями практических задач по анализу данных, автоматизации расчетов и очистке выгрузок.

---

## 📘 Основной курс

* **`excel_tasks_solution.xlsx`** — Сборник задач на логику, поиск и парсинг текста (ВПР, ГПР, ЕСЛИ, текстовые функции).
* **`sales_and_hr_analytics.xlsx`** — Комплексный анализ персонала, расчет KPI премий, анализ фондов оплаты труда (ФОТ) и многокритериальный анализ продаж через `СУММЕСЛИМН` и `СЧЁТЕСЛИМН`.
* **`index_match_and_error_handling.xlsx`** — Продвинутый двумерный поиск через связку `ИНДЕКС`/`ПОИСКПОЗ`, маркетинговая аналитика с обработкой ошибок (`ЕСЛИОШИБКА`) и мультивалютный пересчет.
* **`multi_domain_data_analysis.xlsx`** — Сквозной анализ коммерческих, кадровых, метеорологических и дистрибутивных данных.
